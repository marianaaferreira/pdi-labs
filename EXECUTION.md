# Instruções de execução

## Executar o script do laboratório M1.1

O projeto inclui o script de automação:

```bash
chmod +x script_m1-1.sh
./script_m1-1.sh
```

Esse script executa a configuração, a compilação, os testes e as operações do laboratório M1.1, gerando as imagens de saída em `images/output/`.
